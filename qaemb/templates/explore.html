    The data

    What Sonnet was asked, and how it answered

    Sonnet mostly says no

    Every stated P(yes), all questions and images.

    Most questions are almost never answered yes

    Each question's share of images answered yes (P(yes) ≥ 0.5).

    So we use how sure each answer is, not just yes or no

    Each answer becomes one number, the Directional Score, then standardised per question across the images.

    A question Sonnet almost always answers "no" still carries information: how sure the "no" is varies between images.

    2
    Questions

    Are questions in the same topic answered alike?

    Each topic was asked in one prompt. If its questions move together across the images, either they describe related features, or Sonnet answers a whole prompt from one impression.

    Topic by topic, against random groups of the same size

    Dot: mean correlation between the questions of a topic, blue if above 95% of random groups. Grey bar: random sets of questions of the same size (5th to 95th percentile). Dashed line: mean between topics. Click a topic to see it on the question map.

    Wording does not explain it

    Question pairs binned by how alike they are worded (text embeddings). If wording explained the topic effect, the two lines would meet.

    Two readings, one test

    A · A topic is one feature

    Every vascular-structure question rises when vessels are visible at all. The questions are partly redundant, but each answer is still evidence.

    B · Sonnet answers a prompt from one impression

    "No special-site features here" spreads over 63 questions on nails, palms, face and mucosa, which correlate at . Then an answer is partly the impression, not the feature.

    Test to do

    Ask the same questions one per prompt on about 20 images, and compare the within-topic correlations (Plan item D).

    How many independent things do the questions measure?

    If answers move together, 500 questions measure fewer than 500 things. Principal components count them; clustering shows what they are.

    Variance per component, against shuffled answers

    Components left of the dotted line carry more than the same answers shuffled across images.

    What the main components follow

    Share of each component's variance explained by each variable (0 to 0.5). Click a row for the questions that load most on it.

    The question groups, and which subtypes they mark

    Questions clustered by how alike they are answered, sorted by how well the group separates malignant from benign (AUROC). Cells: the group's mean score in each subtype, in standard deviations (red above average, blue below). Click a row to list its questions.

    Groups follow dermoscopic families (vessels, keratinocyte features, pigment network, blue-grey structures) and the skin around the lesion (photoaging, actinic damage). Artefact groups are the least coherent.

      How many questions does it need?

      The same evaluation with fewer questions, chosen inside each training fold. 27 and 60 are the dimension counts from chapter 3.
